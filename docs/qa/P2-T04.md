## Understood and delivered

One authenticated client-only endpoint branches on booking type, applies bounded
PostGIS discovery, current Connect gates and shared reliability eligibility, and
returns only the existing public projection. Available Now uses the active
session; Scheduled uses configured coverage. Complete database ordering precedes
keyset pagination. Encrypted, authenticated cursors keep private sort keys out of
client-readable data and bind traversal to the verified client and query.

The migration adds private query helpers, service-only guarded public RPCs and
four config rows; it adds no tables, grants no raw private data and changes no
money/status/audit path. Shared validation/domain policies, existing role and
response helpers, shared public identity projection and bounded batch photo
signing are reused. There are no Google/Stripe requests.

## Tests beyond the acceptance list

- Real anonymous/invalid-JWT rejection, stored-role denial for barber/admin and
  unprofiled accounts, forged metadata/body identity, field-level validation.
- Direct RPC denial through the API; private-schema exclusion and migration ACL
  assertions. No new table means no new table RLS policy. Existing raw profile
  read/write denial is covered by the P1-T12 API regression proof.
- Full migration replay and populated upgrade preserve the existing barber
  profile; 25 bounds and 10 exact band cases agree between SQL and pure domain.
- AES-GCM round-trip with fresh nonce; tamper, wrong user/query/key/version and
  invalid/oversized frame rejection. Private keys are never base64 plaintext.
- Batch photo signing makes one deduplicated request, checks returned paths and
  rejects unexpected responses; no request for all-null photos.
- Typed authoritative database role/validation failures remain safe 403/422;
  other failures return generic 500 with a static log marker.
- Runtime config changes take effect immediately. Missing/malformed cursor key
  fails closed. Local wrapper retains JWT verification and rejects hosted targets.
