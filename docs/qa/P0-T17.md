Leave ports 3100/3101 free. Production Next starts at `127.0.0.1:3100`; isolated harness starts
at `127.0.0.1:3101`. Each runner owns/stops its server, never reuses one. Positive harness flow:
page bookings → sort status/reset first page → filter pending payment (2) → no-match empty →
clear filter → open modal → reject whitespace → submit/synthetic failure → retry/success →
focus returned → Escape cancellation → narrow viewport/no horizontal overflow. The harness
browser makes loopback requests only; it never calls a provider or database. Direct production
HTML/RSC checks forge query roles, cookies and headers for anonymous/client/barber/admin/expired;
all remain denied with no-store and no protected payload. The forged admin case is **not** proof
of a real admin login; real sessions do not exist yet.

## AUDIT

Scope: P0-T17 tracked/untracked slice against `9a28116`, guarded Next integration, shared native
presentation refactor, harness, tests, dependency additions and surrounding auth contracts;
checked audit categories A–F. This is a focused code audit, not a whole-repo security certification.

1. **[Major] F — modal keyboard focus handling.** `confirm-dialog.tsx` initially lost the opener
   after success; a stronger boundary check also found Tab leaving its last control. Fixed by
   capturing active element before `showModal()`, focusing the connected opener during cleanup,
   and explicitly wrapping enabled visible controls at Tab/Shift+Tab boundaries. Native modal
   inertness is retained. Real browser assertions first failed, then passed unchanged; see
   [WAI modal keyboard guidance](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/).
2. **[Major] F — crafted null fixture body could terminate its async request.** Fixture server
   originally dereferenced `input.reason` on JSON null. Fixed object/array validation, bounded body
   accumulation, safe async error response and closed-response guard. Direct browser API requests
   now reject malformed/null/extra-field/oversize inputs, followed by a successful real flow.
3. **[Major, triaged] F — inherited dependency maintenance.** [Generated advisory evidence](P0-T17-dependency-audit.json)
   records all 13 alerts and proves every affected package/version already exists on base main.
   No new TanStack alert or vulnerable version was introduced. The package scanner's **critical**
   rating remains unresolved in the repository; this is not downgraded or a clean scan claim.
   `pnpm … why` traces `shell-quote@1.10.0` through React Native devtools, not this new admin flow;
   [its primary advisory](https://github.com/advisories/GHSA-pqg4-j6r4-53mv) requires untrusted
   line-terminated input following a comment token in shell quoting. No shell quoting/command
   execution from user input is added here. `source-map-js@1.2.1` is inherited through Next PostCSS/
   Tailwind and native/test tools; [its advisory](https://github.com/advisories/GHSA-68fv-2mgg-jv7q)
   concerns attacker-supplied indexed source maps, not an input this harness accepts. Next 16.3.7
   has six alerts. No remote image patterns are configured, so [the SSRF advisory's stated
   affected condition](https://github.com/advisories/GHSA-cjq9-62q9-8jv4) is absent. No new Draft
   Mode/cache/metadata image behavior is introduced; the protected route is dynamic and exposes no
   data. Remaining mobile/toolchain alerts are listed in the artifact, not dismissed. **Triage:
   separate owner-reviewed framework/transitive maintenance before deployment**, respecting pinned
   SDK compatibility/release-age policy. Broader exploitability/patch verification is not done in
   this component ticket; no production deployment is authorised here.
4. **[Major] E/F — fixture query/result race.** On an extra browser repeat, a newly requested page
   could briefly show the previous page's rows before the loading effect ran. The fixture caller
   now associates each result with its query, immediately hiding mismatched rows/counts; aborted
   requests cannot overwrite newer state. A held **actual server response** proves the pending
   page has zero stale rows and disabled controls, then renders only the delivered page. No fake
   payload or timeout/retry relaxation used. Owning Phase 5 screens retain this responsibility.
5. **[Minor] D/F — shared type mutability drift.** During review the extracted status type had
   become readonly. Restored the existing native public type shape; no native API break is intended.

Final review checked: guard precedes shell render; no identity/money/status mutation is trusted;
