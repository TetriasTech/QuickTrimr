`POST /rest/v1/rpc/list_barber_booking_requests` returns the verified barber's
unexpired pending requests. It returns the saved service, integer-cent price,
client display name and suburb, coarse distance band, deadline, and requested
Scheduled time. The distance is computed in PostGIS when the request snapshot
is inserted, using the origin already locked and checked during request
creation. The inbox reads that saved band. Existing snapshots keep null when
they predate the band, and the client rating is null. Pagination uses expiry
and request ID as an ordered pair and returns server time for the future UI.

The local QuickTrimr stack ran the migration through `pnpm db:migrate` with
its existing data. With the local functions running, execute
`node scripts/db/verify-barber-inbox.mjs`. The verifier uses real Auth JWTs and
the actual creation endpoint and PostgREST read route. It seeds disposable
supply, excludes synthetic terminal requests, and closes its pending requests
and fixture logins during cleanup. The plan's historical noise is rolled back.

| Acceptance criterion | Evidence |
| --- | --- |
| Own pending requests have the approved fields | Creates an Available Now request and a Scheduled request through the running Edge Function. Exact wire keys and expected service, cents, type, client name, suburb, deadline, Scheduled time and type-specific band are asserted. Changes to the locations, address label data, name and price leave the responses intact. |
| No private location, contact or notes | The raw body is checked field by field against the allowed projection and tested against synthetic private values. A strict schema refuses precise distance, coordinates, notes, phone and a fabricated rating. The private snapshot schema is unavailable to the barber token. |
| Role and ownership enforced | A foreign ID returns the same empty result as a missing ID. A stored-role barber with admin JWT metadata sees only their own rows. Client, admin, absent-profile, unauthenticated and service-role callers are denied. Raw request-table RLS still denies the foreign row. |
| Terminal and elapsed requests excluded | The verifier inserts fixtures for all terminal states and elapsed pending. A lookup for each returns empty. A controlled query check sees the request one millisecond before its deadline and excludes it at and one millisecond after that deadline. |
| Indexed by barber and status | The verifier runs `EXPLAIN (ANALYZE, BUFFERS)` on the same internal SQL read with 4,000 temporary historical rows. It asserts the `booking_requests_barber_inbox_idx` index scan with barber, status and expiry conditions, a bounded 21-row probe and no sort. |
| Stable ordered pages | Asserts 20 rows by default, a maximum of 50, a continuation through tied deadlines, 54 distinct IDs in ascending expiry and ID order, and field errors for malformed cursor or limits. |
| Empty inbox is successful | The authenticated barber receives HTTP 200, an empty requests array and a null cursor before request creation. |
