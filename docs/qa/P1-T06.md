# P1-T06 · Barber profile and service area

Andrew owns [TRIMR-36](https://tetrias-tech.atlassian.net/browse/TRIMR-36). `P0-D06`, `P0-T14`, `P1-T03` and `P1-T05` were Done before implementation. The flow saves the barber's identity, photo and Scheduled service area. Other onboarding steps still determine eligibility for discovery and paid bookings.

## Reproduce

Apply the migration to the local QuickTrimr stack. Load G-NAF as shown in [P1-T05](P1-T05.md); the ACT slice is enough for the live test fixtures. Download the official **Non ABS Structures 2026 GDA2020 GeoPackage ZIP** from the ABS digital boundary page and invoke the importer. It verifies the archive hash before extracting the SAL layer. The migration creates an empty `public_areas` table, so each hosted environment needs both datasets provisioned before the flow works there. [ABS download and licence](https://www.abs.gov.au/statistics/standards/australian-statistical-geography-standard-asgs/edition-4-july-2026-june-2031/access-and-downloads/digital-boundary-files).

```sh
pnpm db:start
pnpm db:migrate
node scripts/db/import-abs-sal.mjs /path/to/ASGS_Ed4_Non_ABS_Structures_GDA2020_GPKG.zip
node scripts/db/local.mjs serve --env-file supabase/.env.local
```

With the Edge runtime serving, run these in a separate shell. They use disposable local account fixtures and public test locations in Canberra.

```sh
node scripts/db/verify-barber-profile.mjs
node scripts/db/verify-client-addresses.mjs
```

The archive SHA-256 was `2e075da92240a20763aac082d2ad904cd87a9ac9168ff6f67e42d5835c4fe33b`. The ABS published this vintage on 14 October 2026. Both the first import and its repeat reported **15,358 spatial areas** from 15,377 source records. The loader skips the non-spatial codes, transforms GDA2020 to WGS 84, and records the source, attribution, date vintage and archive hash. A PostGIS check found zero representative points outside their boundaries. The lookup plan used `public_areas_boundary_idx` and `ST_Covers`. [ABS Suburbs and Localities](https://www.abs.gov.au/statistics/standards/australian-statistical-geography-standard-asgs/edition-4-july-2026-june-2031/non-abs-structures/suburbs-and-localities).

## Public fields and access

`public.public_barber_profiles` retains the existing authenticated ID-only projection. `private.barber_public_profiles` is service-role-only, with `id`, `display_name`, `bio`, `years_experience` and `approximate_area`. Approved client-facing routes can combine that projection with signed photos and ratings after applying eligibility. Exact coordinates, radius, photo IDs, contact information, verification internals and Stripe identifiers belong to private or operational data. The owner profile returns a signed link and the owner's radius. In the case of a point exactly on a shared SAL boundary, the SQL prefers a containing interior, then orders by the official code for a reproducible match.

## Audit and scope

The audit covered the migration, access, Edge operations, mobile form, import and real API tests. It removed over-fetching in the save transaction, made the refreshed signed link follow the profile query, and stopped autocomplete from repeating after selection. Photo objects are immutable so a partial save cannot overwrite the previously published photo. Replaced and abandoned versions remain private in Storage; an object retention and cleanup policy remains operational follow-up. Android and iOS exports passed, with runtime verification on iPhone. Hosted data provisioning and the eligibility-gated client discovery/profile routes are later work.
